
# Restaurant Management System

A beginner-friendly Restaurant Management
System developed using C programming.

## About the Project

This project allows a restaurant to manage
basic food ordering and billing operations.

It was developed as a beginner-level C
programming project to practice fundamental
programming concepts.

## Features

- Display food menu
- Place multiple food orders
- Store customer details
- Select table number
- View current order
- Calculate subtotal and GST
- Generate final bill

## Technologies Used

- C Programming
- GCC Compiler

## Concepts Used

- Variables and Data Types
- Arrays
- Functions
- If-Else Statements
- Switch Statements
- For Loops
- Do-While Loops
- Arithmetic Operators

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Compile the source code:

   gcc src/main.c -o restaurant

4. Run the program:

   ./restaurant

   On Windows, run restaurant.exe.
